# Hi, I’m Mohammadjavad (Javad) Maheronnaghsh 👋

I’m an **AI Engineer and ML Scientist / Researcher based in Toronto**, focused on **LLMs, agentic AI, and efficient machine learning systems**.

I hold an **M.A.Sc. in Electrical & Computer Engineering from the University of Toronto**, where my research involved collaboration with **Meta**. Previously, I worked as an **AI Engineer at ArcTrade**, building AI tools for software review, testing, and documentation.

I approach problems from the user’s perspective: define success, establish a baseline, then build and evaluate. I bring that same discipline to AI systems, with an emphasis on reliability, practical deployment, and measurable impact.

## What I build

* **LLM applications and AI agents:** Systems for developer workflows, academic outreach, and news briefing.
* **Reliable AI workflows:** Tools and evaluation processes that help assess model behavior and improve software quality.
* **Efficient ML systems:** Model design, optimization, and evaluation across GPU, edge, and FPGA deployment settings.
